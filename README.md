Trophy Dilution Forecaster — forecasts each Grand Theft Auto VI PlayStation 5 trophy's Exophase earn rate one week after launch, as five quantiles, from the reads the house recorded up to the case checkpoint. It models every trophy's earned count and the tracked-player count separately (a rate is earned players divided by tracked players, and both grow), projects both to the target, and widens its spread with the horizon and with how flat the history is, so a refresh that reveals a wave of new tracked players still lands inside the forecast band.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./out python3 main.py
````
